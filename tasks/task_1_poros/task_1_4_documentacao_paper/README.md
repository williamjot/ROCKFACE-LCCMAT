# Task 1.4 — Documentação das decisões e paper ⏳

Registrar as decisões das Tasks 1.1–1.3 e viabilizar a produção de um paper.

Lacunas levantadas na Task 1.1 que podem virar contribuição:

- não há benchmark público de segmentação de poros com resina azul com máscaras por pixel;
- faltam comparações diretas entre classificadores clássicos com anotação esparsa e
  limiares de cor, medidas em métricas petrofísicas;
- poucos trabalhos avaliam o efeito de treinar com rótulos gerados por limiar.
